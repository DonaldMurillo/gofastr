# GoFastr branding

## Primary logo concept

The primary GoFastr logo combines the project's existing lambda motif with
three forward rails. The lambda represents the small declarative blueprint;
the rails represent the readable Go, UI, API, and agent-facing surfaces that
fan out from it. The compact geometry is intended to remain recognizable when
reduced to an app icon.

The horizontal lockup is stored at
[`assets/brand/gofastr-logo.png`](../assets/brand/gofastr-logo.png). It is an
RGBA PNG with a transparent background. The amber mark follows the docs site's
warm accent direction, while the near-black wordmark is intended for light
surfaces.

This is an initial raster concept, not a finalized vector master. Before using
it as permanent release branding, redraw the selected geometry as SVG, define
exact color values, and prepare light-surface, dark-surface, symbol-only, and
monochrome variants.

## Concept explorations

Four deliberately different follow-up directions are stored alongside the
initial concept:

- `gofastr-logo-v2-speed-kiln.png` — blueprint ribbon enters an abstract
  compiler chamber and exits as a finished artifact.
- `gofastr-logo-v3-gf-monogram.png` — interlocking `g` and `f` geometry built
  from nested, declaration-like strokes.
- `gofastr-logo-v4-lambda-forward.png` — the existing lambda motif reduced to
  one continuous forward gesture.
- `gofastr-logo-v5-wordmark.png` — a wordmark-first direction using a small
  amber colon as the declaration/code detail.

These are raster concept studies. Select the strongest visual idea before
refining typography or producing final vector variants.

## Preliminary originality screen

Screened 2026-07-16. This is a practical collision check, not legal trademark
clearance.

- The `GF` monogram category is crowded. VectorStock currently lists thousands
  of `GF` logo vectors, and other stock libraries include orange-and-black
  interlocking `GF` marks. The v3 geometry did not appear as an exact match in
  the reviewed results, but the initials, palette, and generic interlocking
  construction are not distinctive enough to ship unchanged.
- `gofastr` has prior software-package use: CRAN's archive contains three
  releases of an R package with that exact lowercase name from 2017. Nearby
  `Fastr` software brands also operate in developer tooling and web software.
- Broad indexed searches did not surface an obvious exact `GOFASTR` US
  trademark record. That is not a database clearance result. Before commercial
  adoption, search the USPTO database for the exact wording, expanded wording,
  phonetic variants, and relevant software/service classes, then repeat in
  other intended markets.

If the v3 direction is retained, redraw it around a GoFastr-specific structural
idea—such as a one-to-many blueprint expansion or literal YAML indentation—so
the silhouette is more than an interlocking pair of initials. Avoid the common
orange-on-black stock-monogram treatment in the final master.

Four v3 refinement studies apply that recommendation:

- `gofastr-logo-v3a-yaml-nesting.png` — three progressively indented
  declaration strokes resolve into a compact mark.
- `gofastr-logo-v3b-one-to-many.png` — one amber input becomes four charcoal
  outputs inside an open code-block silhouette.
- `gofastr-logo-v3c-owned-code.png` — an amber YAML colon sits between open
  square brackets, emphasizing readable, editable output.
- `gofastr-logo-v3d-blueprint-fold.png` — indented declaration lines fold into
  a generated document or code artifact.

Of these, v3b expresses the framework's differentiator most directly and has
the best basis for a more ownable symbol. It should still be redrawn as a
precise vector and screened again after the geometry is finalized.
