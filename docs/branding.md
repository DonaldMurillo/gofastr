# GoFastr branding

## Logo

The GoFastr logo combines the project's lambda motif with three forward
rails. The lambda represents the small declarative app spec; the rails
represent the readable Go, UI, API, and agent-facing surfaces that fan out
from it. The compact geometry is meant to stay recognizable when reduced to
an app icon.

The horizontal lockup is
[`assets/brand/gofastr-logo.png`](../assets/brand/gofastr-logo.png): an RGBA
PNG with a transparent background, an amber mark and a near-black wordmark
for light surfaces.

It is a raster concept, not a vector master. Before using it as permanent
release branding, redraw it as SVG, define exact color values, and prepare
light-surface, dark-surface, symbol-only, and monochrome variants. Other
directions explored in 2026-07 are in git history.

## Name screen

Screened 2026-07-16. This is a practical collision check, not legal
trademark clearance.

- `gofastr` has prior software-package use: CRAN's archive holds three
  releases of an R package with that exact lowercase name from 2017.
  Nearby `Fastr` brands also operate in developer tooling and web software.
- Broad indexed searches did not surface an exact `GOFASTR` US trademark
  record. That is not a database clearance. Before commercial adoption,
  search the USPTO database for the exact wording, expanded wording,
  phonetic variants, and the relevant software and service classes, then
  repeat in other intended markets.
- The `GF` monogram category is crowded with stock interlocking marks, often
  orange on black. Avoid that treatment in a final mark.
