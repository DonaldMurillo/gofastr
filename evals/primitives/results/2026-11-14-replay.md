# Replay suite, 2026-11-14

Claude Code CLI 2.1.325. Three past bugs, each started from the commit
before its fix. Haiku 3 trials, Sonnet 2 trials: 30 cells, $3.76.

| | plain | nudge |
|---|---|---|
| Reported path fixed | 15/15 | 14/15 |
| Other paths with the same defect fixed | 5/30 | 25/30 |

By task, other paths fixed (Haiku, then Sonnet):

| Task | plain | nudge |
|---|---|---|
| `repeated-query-key` (3 paths) | 3/9, 2/6 | 8/9, 6/6 |
| `observer-panic` (1 path) | 0/3, 0/2 | 3/3, 2/2 |
| `undecodable-filter` (2 paths) | 0/6, 0/4 | 4/6, 2/4 |

- **Agents fix what is reported and stop.** Without the nudge they fixed
  the reported path every time and one in six of the other paths. The
  one they did reach was the same function's neighbouring query key.
- **One sentence closed most of the gap.** "Before you finish, check
  whether other code paths have the same defect, and fix those too" took
  the other paths from 5/30 to 25/30, on both models.
- **It costs more.** A nudged Haiku cell used about twice the tool calls
  of a plain one; Sonnet cells cost about the same either way.

The one `nudge` cell marked unfixed (Sonnet, `undecodable-filter`) did
add a warning, but worded it as the audit page's existing callout
instead of "Filter not applied", and said so. The grader matches the
text, so it scored that cell 0.

## With the registry instead of the sentence

A third condition gave the old trees the registry: `primitives for` on a
touched file names the other paths that do the same job. No sentence was
added to the prompt. 30 more cells, $3.11.

| Other paths fixed | plain | registry, first wording | registry, firm wording | nudge |
|---|---|---|---|---|
| Haiku | 3/18 | 3/18 | 5/18 | 15/18 |
| Sonnet | 2/12 | 3/12 | 8/12 | 10/12 |

First wording: "A defect or a change in one of these probably belongs in
all of them. Check each before you finish." Firm wording: "In this
repository a fix to one of these is not finished until every site has
it. Fix them all, or say why a site is exempt."

- **Told by a tool is weaker than told by the person.** With the first
  wording, agents that read the notice fixed the reported path and
  listed the other paths in their summary as "not checked". The firm
  wording moved Sonnet most of the way and Haiku very little.
- **The lookup is skipped about a third of the time.** 11 of 30 registry
  cells never ran `primitives for` or read `primitives/`, on the
  strength of one paragraph in `CLAUDE.md`.
- **Not tested: a hook.** A PreToolUse hook that prints the notice when
  a file is edited would close the second gap. Project hooks did not
  fire under `claude -p` in the sandbox these runs used.

Three tasks, all of the "same defect on a sibling path" kind, two or
three trials a cell. The nudge names that kind of mistake exactly, so
this shows the instruction works for it, not that it generalises.
