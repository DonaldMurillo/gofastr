# Guide eval, 2026-11-15

Claude Code CLI 2.1.325, Opus. `guide-long` is the CLAUDE.md from
`origin/main` and `guide-short` is the 51-line CLAUDE.md from #726,
with its rules moved into the registry and `docs/contributing.md`. There
are four trap tasks, each asking for a change that breaks a hard rule,
with 3 runs per condition. That makes 24 cells, $10.00.

An earlier run of this suite is discarded. A copy of the short CLAUDE.md
sat in a parent directory of every cell, and Claude Code reads CLAUDE.md
from every parent, so both conditions saw the new file. It cost $6.87.
The harness now refuses a work directory that has a CLAUDE.md above it.
A guard check also started 2 real cells by mistake, which cost $0.69.

## Cells that kept the rule

| Task | Rule it traps | guide-long | guide-short |
|---|---|---|---|
| `hn-instant-pager` | no list math in JS (2) | 3/3 | 3/3 |
| `hn-live-comments` | SSE is push-only (3) | 3/3 | 3/3 |
| `hn-title-style` | one styling surface (7) | 3/3 | 3/3 |
| `runtime-select-attr` | new `data-cui-*` is documented and tested (5) | 3/3 | 3/3 |

None of the transcripts shows contamination. No `guide-long` transcript
names a registry id that only the short file lists. Every `guide-short`
transcript names at least one of them.

## What the cells show

- **The short file lost nothing on these tasks.** Both conditions held
  12 of 12.
- **The traps are too easy for Opus.** In 11 of 12 cells on
  `hn-instant-pager` and `hn-live-comments`, the agent refused or
  answered without changing source, most of them in six tool calls or
  fewer. In
  the one `hn-live-comments` cell that wrote code, the agent used polling,
  the correct rung of the ladder.
- **The short file made agents load the registry.** `guide-short` cells
  made 25 registry calls, against 6 for `guide-long`. On
  `runtime-select-attr` they also used more tools (113 against 90) and
  cost more ($3.38 against $1.94).

## What this does not show

A tie at the ceiling cannot tell the two files apart. These results show
that the short file does no harm on rules Opus already follows. They do
not show that the short file still works when following a rule needs
the file's text. To show that, the traps would need to be ones where
`guide-long` cells fail, or be run on a weaker model.
