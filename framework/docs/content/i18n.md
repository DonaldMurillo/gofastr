# Internationalization (`core/i18n`)

GoFastr's i18n package handles message catalogs, request locale negotiation, URL locale prefixes, pluralization, and locale-aware formatting with zero third-party dependencies.

## Quickstart

Define phrases at package level and register translations in a catalog:

```go
import (
	"github.com/DonaldMurillo/gofastr/core/i18n"
	"github.com/DonaldMurillo/gofastr/framework"
)

var greeting = i18n.Define("app.greeting", "Hello, {{name}}!")

cat := i18n.NewMapCatalog()
cat.Set("en", "app.greeting", i18n.Message{Text: "Hello, {{name}}!"})
cat.Set("es", "app.greeting", i18n.Message{Text: "¡Hola, {{name}}!"})

app := framework.NewApp(
	framework.WithI18n(i18n.NewTranslator(cat, "en")),
)
```

Render translated strings using the request context:

```go
msg := greeting.Text(ctx, map[string]any{"name": "Ada"})
```

Built-in `framework/ui`, `battery/setup`, and `framework/localentity` strings automatically follow the resolved request locale when `WithI18n` is configured.

## Resolving locale per request

By default, `WithI18n` negotiates the locale from `Accept-Language` (and adds `Vary: Accept-Language, X-Locale` for caches). Add `framework.WithLocaleResolver(...)` to read a user preference cookie or profile setting ahead of `Accept-Language`.

When implementing a locale-switcher endpoint, set safe cookie attributes and never redirect to a raw `Referer` header:

<!-- gofastr:compile
import "github.com/DonaldMurillo/gofastr/framework"
var app = framework.NewApp()
import "net/http"
import "net/url"
import "strings"
-->
```go
func setLocale(w http.ResponseWriter, r *http.Request) {
	lang := r.FormValue("lang") // validate against your catalog
	http.SetCookie(w, &http.Cookie{
		Name:     "locale",
		Value:    lang,
		Path:     "/",
		HttpOnly: true,
		Secure:   true,
		SameSite: http.SameSiteStrictMode,
	})
	http.Redirect(w, r, backToSender(r), http.StatusSeeOther)
}

// backToSender turns the Referer into a same-origin relative path, "/"
// when it is anything else (missing, absolute on another host, or a
// protocol-relative URL). The Referer header is attacker-controlled;
// redirecting to it raw is an open redirect.
func backToSender(r *http.Request) string {
	u, err := url.Parse(r.Referer())
	if err != nil || u.Host != "" && !strings.EqualFold(u.Host, r.Host) {
		return "/"
	}
	if p := u.Path; strings.HasPrefix(p, "/") && !strings.HasPrefix(p, "//") {
		return p
	}
	return "/"
}
```

`WithLocaleResolver` panics if used without `WithI18n`.

### Locale in the URL

`framework.WithLocalePrefixes` mounts every non-fallback catalog locale under `/<tag>/` (for example `/es/pricing`), while keeping unprefixed paths (`/pricing`) for the fallback locale:

- The router strips the locale prefix before matching handlers and injects the locale into `r.Context()`.
- `<html lang>`, `hreflang` links, sitemaps, PWA manifests, and static exports (`gofastr export`) automatically emit per-locale variants.
- API routes and framework endpoints (`/api`, `/__gofastr/...`) stay unprefixed.

## Plurals, errors, and formatting

- **Placeholders:** `{{name}}` interpolation; missing placeholders stay visible as `{{name}}` during development.
- **Plurals:** use plural keys (`.one` / `.other` and CLDR categories) via the catalog helpers for count-dependent messages.
- **Localized errors:** wrap user-facing validation errors with `i18n.NewError(phrase)` so handlers and forms render messages in the caller's language.
- **Formatting:** format dates, numbers, and currencies using the resolved locale tag, and keep `<html lang>` stamped so browser controls and `localentity` number parsing match.

## Loading catalogs from files

Embed JSON or key-value catalog files with `//go:embed` and load them into `i18n.NewMapCatalog()` at startup so translators can edit locale files without touching Go code.

## Common mistakes

- **Redirecting straight to `r.Referer()` in a locale switcher:** `Referer` is caller-controlled and creates an open redirect. Always sanitize to a same-origin path.
- **Calling `WithLocaleResolver` without `WithI18n`:** panics at startup because there is no catalog to negotiate against.
- **Setting the locale cookie without `HttpOnly`, `Secure`, and `SameSite`:** follow the same cookie posture as session cookies.
- **Translating database enum values or log messages:** keep stored values, API keys, and server logs in canonical identifiers; translate only UI copy at render time.
- **Forgetting to pass `ctx` into `phrase.Text(ctx, ...)`:** without the request context, phrases fall back to the default locale.
